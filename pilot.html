03 / What the pilot asks

From generalization
to policy improvement.

Each question builds on the previous one: transfer suggests a model, prediction tests it, and improved choices test its use for learning.

Does practice transfer to new configurations?

Compare delivery success after 0, 200, or 400 training launches on five new fields.

Transfer suggests an internal model, but generalizable model-free representations remain an alternative. Question 2 tests predictive knowledge directly.

Key measures

  • Delivery rate on early encounters.
  • Closest approach when a launch misses.

The generalization test provides feedback, so later trials also reflect new learning.

Does practice improve trajectory prediction?

Participants launch, then draw the expected flight on five further new fields. The actual trajectory stays hidden.

Accurate prediction requires a model of action consequences. Question 3 asks whether this model can improve choices.

Key measures

  • Distance between drawn and true paths.
  • Predicted outcome: delivery, crash, or exit.
  • Accuracy beyond a straight-line baseline.

Account for flight complexity. Without a prediction pretest, this is a comparison between groups.

Do choices improve while predicting?

Across 90 prediction trials, can model-generated consequences and predicted reward improve action selection without new outcome feedback?

Link changes in launch success to the same participant’s prediction accuracy. Success is recorded by the task but hidden from participants.

Key measures

  • Increasing delivery rates or smaller misses.
  • Changes in launch choices within each field.
  • Whether better predictions accompany greater improvement.

A later launch-only test would help distinguish retained policy improvement from planning on each trial.

04 / Link to the imagery project

Learning from imagined consequences.

Can motor imagery help people discover and select better movements?

This pilot tests the proposed mechanism: an internal model generates simulated experience that may improve the policy. Drawing makes predictions measurable; motor imagery itself remains to be tested.

Design considerations
  • Control still receives test feedback. Every group completes the same warm-ups and generalization test.
  • Prediction and choice are linked outcomes. Better drawings alone do not establish policy improvement.
  • Next step: test whether imagined alternatives improve movement solutions, robustness, and consistency.
